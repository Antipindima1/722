# Ф2. Выплата по СБП

## Цель

Выплатить проверенные строки реестра одним пакетом через СБП и получить по каждой выплате
чек ФНС. Источник фичи: `Задание п. 8` («фичи на выбор»).

## Пользователь

Бухгалтер компании (запуск и разбор ошибок); исполнитель-самозанятый (получатель).

## Сценарий

1. Бухгалтер запускает выплату по реестру в статусе «Проверен».
2. Проверяются: статус самозанятого в ФНС (`CHK-08`), состояние реестра (`CHK-09`),
   средства (`CHK-10`), отсутствие активной выплаты (`CHK-11`), суточный лимит (`CHK-12`).
3. Строки отправляются в СБП; каждая строка обрабатывается независимо (`AS-06`).
4. Результат по строке: «Выплачена» либо «Ошибка» с причиной; при технической ошибке —
   ретраи (`AS-17`).
5. По каждой успешной выплате запрашивается чек ФНС (`O-05`, `AS-07`).
6. Реестр закрывается в «Завершён» или «Завершён с ошибками».

## Результат

Выплаты исполнены, чеки получены, реестр закрыт; проблемные строки и неполученные чеки
видны бухгалтеру в отчёте.

## Применимые правила

`O-01`, `O-02`, `O-04`, `O-05`, `CHK-08…CHK-12`; статусы
[[02-business-rules#4.3. Выплата]] и [[02-business-rules#4.4. Чек ФНС]]; допущения
`AS-05`, `AS-06`, `AS-07`, `AS-11`, `AS-12`, `AS-13`, `AS-17`.

## Критерии приёмки (для проверки артефакта)

- Есть операция запуска пакетной выплаты и операция получения статуса по строке.
- Идемпотентность выражена ключом, а не соглашением «не повторять» (`AS-13`).
- Поведение при отказе СБП и при исчерпании ретраев описано явно (`AS-17`).
- Ни в одном месте не допускается выплата без подтверждённого статуса самозанятого
  (`O-02`, `CHK-08`).
- Получение чека отражено как обязательный шаг со статусом «Не получен» (`O-05`, `AS-07`).
