# Платёж (Payment)

Итоговое списание стоимости поездки. Источник: `BRD 7.3.3`, `BRD 8.4`.

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `payment_id` | Идентификатор платежа | `BRD 8.4` |
| `trip_id` | Поездка, за которую платят | `BRD 8.4` |
| `amount` | Итоговая сумма | `PAY-01` |
| `status` | Статус платежа | `BRD 8.4` |
| `attempts` | Число попыток списания | `PAY-03`, `AS-08` |
| `debt_amount` | Остаток задолженности | `PAY-03` |

## Статусы

«Ожидает результата» → «Оплачен» / «Не оплачен»; «Не оплачен» → повтор или «Оплачен
частично»; «Оплачен частично» → «Ожидает результата» / «Оплачен». Переходы —
[[02-business-rules#4.4. Платёж]].

## Расчёт

- Тариф: 9 ₽/мин движение, 3 ₽/мин парковка/ожидание, минимум 50 ₽ (`AS-06`).
- Округление: длительность вверх до минуты, стоимость до рубля (`AS-07`).
- Модель фиксирована, динамического ценообразования нет (`O-06`).

## Правила

- Ретраи: 3 попытки с интервалами 1 / 5 / 15 минут, затем задолженность (`PAY-03`, `AS-08`).
- При задолженности старше 24 часов клиент блокируется для новых броней (`PAY-04`, `AS-09`).
- Повторная операция с тем же ключом не создаёт второе списание (`CHK-12`, `AS-16`).
