# Клиент

Пользователь сервиса, физлицо. Источник: `BRD 2`, `BRD 4`, `C4`.

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `user_id` | Идентификатор из `JWT` | `API 1.2` |
| `documents` | Проверенные документы и право управления | `BRD 4` |
| `is_blocked` | Блокировка из-за задолженности | `PAY-04` |
| `debt_amount` | Текущая задолженность | `PAY-03`, `AS-09` |
| `active_bookings` | Число активных броней | `BR-02`, `AS-02` |

## Допуск клиента

Перед бронированием проверяются: документы (через сервис проверки документов), отсутствие
блокировки, отсутствие задолженности — `CHK-01`, `BR-04`, `PAY-04`.

## Правила

- Не более 1 активной брони (`AS-02`).
- Блокировка при задолженности старше 24 часов; снимается после погашения (`AS-09`).
- Данные обрабатываются по 152-ФЗ, доступ к фото — по заявке (`AS-20`, `O-07`).
