# Залог (обеспечительный платёж)

Предварительная блокировка средств клиента на стороне платёжного провайдера. Источник:
`BRD 5.1`, `BRD 7.3.3 / PAY-02`, `BRD 8.3`.

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `deposit_id` | Идентификатор операции залога | `BRD 8.3` |
| `booking_id` / `trip_id` | К чему относится залог | `BRD 8.3` |
| `amount` | Сумма блокировки | `PAY-02` |
| `status` | Статус залога | `BRD 8.3` |
| `withheld_amount` | Удержанная часть при частичном удержании | `BRD 8.3` |
| `hold_ref` | Ссылка на операцию у провайдера | `O-03` |

## Статусы

«Средства не захолдированы» → «Выполняется холд» → «Средства захолдированы» /
«Не удалось захолдировать»; из «захолдированы» — «Холд отменён», «Частично удержаны»,
«Полностью удержаны». Переходы — [[02-business-rules#4.3. Залог]].

## Правила

- Холд выполняется до подтверждения брони; при `HoldFailed` бронь отменяется
  (`API 2.2.3`).
- Удержание возможно только по решению уполномоченного лица и в пределах лимита
  (`DMG-02`, `DMG-03`, `AS-05`).
- Снятие холда инициируется после закрытия поездки, фактический возврат — T+1…T+3
  (`AS-15`).
- Сроки действия залога и порядок снятия определяет платёжный провайдер (`O-03`).
