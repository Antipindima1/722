# Чек ФНС (Receipt)

Документ, подтверждающий доход самозанятого. Сервис получает чек по каждой выплате.
Источник: `Описание продукта`, `O-05`.

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `receipt_id` | Идентификатор чека | `AS-16` |
| `payout_id` | Выплата, по которой чек | [[payout]] |
| `contractor_id` | Исполнитель | [[contractor]] |
| `amount` | Сумма дохода | `O-05` |
| `status` | Статус чека | [[02-business-rules#4.4. Чек ФНС]] |
| `received_at` | Когда получен | `AS-07` |

## Статусы

Ожидается → Получен / Не получен; из «Не получен» — повторный запрос. Переходы — в
[[02-business-rules#4.4. Чек ФНС]].

## Правила

- Чек обязателен: выплата без чека считается незавершённой (`O-05`).
- Срок ожидания — 24 часа, затем признак «Чек не получен» и отчёт бухгалтеру (`AS-07`).
- Аннулирование чека при возврате — вне выбранных фич (`AS-08`).
