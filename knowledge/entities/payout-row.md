# Строка реестра (Payout row)

Одна запись реестра: один исполнитель, сумма и назначение платежа. Источник:
`Задание п. 8`, `AS-01`.

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `row_id` | Идентификатор строки внутри реестра | `AS-13` |
| `registry_id` | Реестр, к которому относится строка | [[registry]] |
| `full_name`, `inn`, `phone` | Данные исполнителя | `AS-01` |
| `amount` | Сумма выплаты | `AS-02` |
| `purpose` | Назначение платежа | `AS-01` |
| `status` | Статус строки | [[02-business-rules#4.2. Строка реестра]] |
| `reject_reason` | Причина отклонения | `CHK-03…CHK-07` |

## Статусы

Новая → Проверена / Отклонена → В выплате → Выплачена / Ошибка. Переходы — в
[[02-business-rules#4.2. Строка реестра]].

## Правила

- ИНН проверяется по контрольной сумме (`AS-09`), телефон — на пригодность для СБП (`AS-10`).
- Сумма больше нуля и не выше лимита одной выплаты (`AS-02`).
- Дубли ИНН в реестре отклоняются (`O-08`).
- Повторная отправка не создаёт второй перевод (`AS-13`).
