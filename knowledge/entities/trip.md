# Поездка (Trip)

Период использования автомобиля клиентом: от подтверждённого открытия до закрытия.
Источник: `BRD 8.2`, `BRD 4`.

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `trip_id` | Идентификатор поездки; к нему привязаны фото | `C4`, `AS-11` |
| `booking_id` | Бронь, из которой создана поездка | `BRD 8.1` |
| `started_at`, `finished_at` | Границы поездки для тарификации | `BRD 4` |
| `photos_before`, `photos_after` | Фотофиксация состояния до и после | `START-01`, `END-02` |
| `distance`, `duration` | Данные для расчёта, приходят из телематики | `BRD 4` |
| `close_reason` | Причина ручного закрытия оператором | `BRD 3.1` |

## Статусы

Готов к началу → Выполняется → Ожидает завершения → Завершена; ветки «Отменена» и
«Закрыта оператором». Переходы — [[02-business-rules#4.2. Поездка]].

## Правила

- Старт только при выполненной фотофиксации (`START-01`), выполненных условиях старта
  (`START-02`) и подтверждённом открытии автомобиля.
- Завершение только в разрешённой геозоне (`END-01`), при подтверждённом закрытии
  (`END-03`) и фотофиксации после поездки (`END-02`).
- Если телематика не подтверждает закрытие — поездка не считается завершённой, запускается
  повторная обработка или передача оператору (`O-05`, `END-03`).
- Недоступность карт блокирует завершение, оператор может закрыть вручную (`AS-12`).
