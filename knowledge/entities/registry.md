# Реестр выплат (Registry)

Пакет строк, загруженный бухгалтером за один раз: кому, сколько и за что платить.
Источник: `Задание п. 8`, [[feature-registry-check]].

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `registry_id` | Идентификатор реестра | `AS-13` |
| `file_name`, `uploaded_at` | Файл и момент загрузки | `AS-01` |
| `row_count`, `total_amount` | Количество строк и сумма | `AS-02` |
| `status` | Статус реестра | [[02-business-rules#4.1. Реестр выплат]] |
| `error_share` | Доля отклонённых строк | `AS-14` |
| `account_id` | Счёт списания компании | `AS-03` |

## Статусы

Загружен → Проверяется → Проверен / Заблокирован → В выплате → Завершён /
Завершён с ошибками; ветки «Отклонён» и «Отменён». Переходы — в
[[02-business-rules#4.1. Реестр выплат]].

## Правила

- Формат и обязательные поля — `AS-01`; лимиты — `AS-02`; одна валюта и счёт — `O-07`.
- Дубли ИНН не допускаются (`O-08`).
- При доле ошибок выше 10% реестр блокируется (`AS-14`).
- Частичное исполнение допускается (`AS-06`).
