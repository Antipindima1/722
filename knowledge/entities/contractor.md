# Исполнитель (Contractor)

Самозанятый получатель выплаты: курьер, репетитор и т.п. Источник: `Описание продукта`.

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `contractor_id` | Идентификатор исполнителя | `AS-13` |
| `inn` | ИНН, ключ сопоставления с ФНС | `AS-09` |
| `full_name` | ФИО | `AS-01` |
| `phone` | Телефон для СБП | `AS-10` |
| `self_employed_status` | Статус самозанятого на момент проверки | `CHK-08` |
| `status_checked_at` | Когда проверяли | `AS-05` |

## Статус самозанятого

Проверяется в ФНС («Мой налог») перед каждой выплатой, без переиспользования результата
проверки при загрузке (`AS-05`). Если статус утрачен — выплата запрещена (`O-02`).

## Правила

- Только самозанятые (`O-01`); выплата без действующего статуса запрещена (`O-02`).
- Персональные данные маскируются (`AS-15`).
- Один ИНН не может встречаться в реестре дважды (`O-08`).
