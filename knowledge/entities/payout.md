# Выплата (Payout)

Операция перевода денег исполнителю; в MVP — только по СБП. Источник: SA-2378,
[[feature-sbp-payout]].

## Атрибуты

| Атрибут | Смысл | Источник |
|---|---|---|
| `payout_id` | Идентификатор выплаты | `AS-13` |
| `row_id`, `registry_id` | Строка и реестр-источник | [[payout-row]] |
| `contractor_id` | Получатель | [[contractor]] |
| `amount` | Сумма перевода | `AS-02` |
| `status` | Статус выплаты | [[02-business-rules#4.3. Выплата]] |
| `sbp_ref` | Ссылка на операцию в СБП | `AS-16` |
| `attempts` | Число попыток | `AS-17` |

## Статусы

Создана → Отправлена в СБП → Исполнена / Отклонена; из «Отклонена» — повторная попытка.
Переходы — в [[02-business-rules#4.3. Выплата]].

## Правила

- Выплата только самозанятому с действующим статусом (`O-01`, `O-02`, `CHK-08`).
- Отправка возможна только из реестра в статусе «Проверен» (`CHK-09`).
- Нужна достаточность средств (`CHK-10`) и соблюдение суточного лимита (`CHK-12`).
- Ретраи: 3 попытки, затем «Ошибка» и DLQ (`AS-17`).
- Возврат — вне выбранных фич (`AS-08`).
