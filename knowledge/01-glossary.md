# Глоссарий

Термины сгруппированы по смыслу. В скобках — источник: `Vision`, `BRD`, `API`, `C4`;
если источник не указан, определение сформулировано по контексту артефактов, а спорные
детали вынесены в [[03-assumptions]].

## Роли и участники

| Термин | Определение |
|---|---|
| Клиент | Пользователь сервиса, физлицо; выбирает автомобиль, создаёт и отменяет бронь, начинает и завершает поездку, оплачивает её. `BRD 2` |
| Допуск клиента | Проверка права пользоваться сервисом: документы, отсутствие блокировки, отсутствие задолженности. `BRD 3.1`, `BRD 4` |
| Операционная команда | Контролирует доступность автомобилей и исключения, участвует в разборе инцидентов. `BRD 2` |
| Оператор | Сотрудник поддержки, который разбирает исключения и может закрыть поездку вручную с указанием причины. `BRD 3.1`, `BRD 4` |
| Финансовая служба | Определяет правила тарификации, залога, списаний, возвратов и задолженности. `BRD 2` |

## Аренда и поездка

| Термин | Определение |
|---|---|
| Каршеринг | Краткосрочная аренда автомобилей с поминутной оплатой; полный цикл от брони до расчётов. `Vision 1` |
| Автомобиль | Объект аренды; его состояние, открытие/закрытие и координаты приходят из телематики. `Vision 7.2`, `C4` |
| Бронирование (бронь) | Резерв конкретного автомобиля за клиентом на ограниченный срок с контролем доступности. `Vision 6`, `BRD 4` |
| Поездка | Период использования автомобиля клиентом: от подтверждённого открытия до закрытия. `BRD 8.2` |
| Начало поездки | Момент, когда выполнены условия старта, автомобиль открыт и аренда переведена в активное состояние. `BRD 4` |
| Завершение поездки | Проверка геозоны и закрытия автомобиля, фиксация состояния после поездки и закрытие аренды. `BRD 4` |
| Геозона | Разрешённая зона завершения поездки; проверяется через картографический сервис. `BRD 6`, `BRD 7.3.4 / END-01` |
| Фиксация состояния | Фото- и видеофиксация автомобиля до и после поездки с привязкой к поездке. `BRD 5.1`, `START-01` |
| Кейс повреждения | Обращение по расхождению состояния автомобиля до и после поездки; решение об удержании принимает оператор. [[damage-case]] |

## Тарификация и деньги

| Термин | Определение |
|---|---|
| Тарификация | Расчёт стоимости бронирования, использования автомобиля и парковки по тарифу. `BRD 7.3.3 / PAY-01` |
| Поминутная тарификация | Способ расчёта, при котором стоимость зависит от времени использования. `BRD 3.1` |
| Режим парковки/ожидания | Отдельный режим тарификации, когда автомобиль не движется, но аренда продолжается. `BRD 4` |
| Залог (обеспечительный платёж) | Предварительная блокировка средств на стороне платёжного провайдера для обеспечения обязательств клиента. `BRD 5.1`, [[deposit]] |
| Холд | Техническая операция блокировки суммы залога; результат приходит событием `HoldSucceeded` / `HoldFailed`. `API 2.2` |
| Удержание | Списание части или всей суммы залога на установленном основании (например, подтверждённое повреждение). `BRD 8.3`, `DMG-02` |
| Платёж | Итоговое списание стоимости поездки; может завершиться частичной оплатой и задолженностью. `BRD 8.4`, [[payment]] |
| Задолженность | Непогашенная часть стоимости поездки после исчерпания попыток списания. `BRD 6`, `PAY-03` |
| Блокировка клиента | Ограничение услуг (запрет новых броней) при сформированной задолженности. `BRD 3.1`, `PAY-04` |

## Интеграции и техника

| Термин | Определение |
|---|---|
| Телематическая система | Внешняя система: состояние автомобиля, команды открытия/закрытия, события и координаты. `Vision 7.2` |
| Платёжный шлюз / эквайринг | Внешняя система: холд, списание, возврат, результат операции. `Vision 7.2` |
| Сервис проверки документов | Внешняя система подтверждения личности и права управления автомобилем. `Vision 7.2` |
| Сервис уведомлений | Внешняя система доставки сообщений клиенту о событиях аренды. `Vision 7.2` |
| API Gateway | Единая точка входа для мобильного приложения и веб-интерфейса. `C4` |
| Сервис бронирования | Управляет жизненным циклом брони, хранит брони в Booking DB, публикует события в Kafka. `C4` |
| Сервис поездок | Управляет поездкой, хранит поездки в Trip DB, работает с файловым хранилищем фото. `C4` |
| Сервис управления авто | Хранит состояние автомобилей, общается с телематикой. `C4` |
| Финансовый сервис | Считает стоимость, работает с платёжной системой и холдами, хранит транзакции. `C4` |
| Сервис клиентов | Допуск клиента, документы, профиль. `C4` |
| Notification Service | Подписывается на события Kafka и отправляет уведомления. `C4` |
| Outbox Publisher | Механизм публикации событий из БД сервиса в Kafka без потери при сбое. `API 2.1` |
| DLQ | Очередь недоставленных сообщений после исчерпания повторов. `API 2.2.1.1` |
| Идемпотентность | Свойство операции не менять результат при повторном выполнении; обеспечивается ключом идемпотентности и проверкой `event_id`. `API 1.3`, `API 2.2.1.2` |
