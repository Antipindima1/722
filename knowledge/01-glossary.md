# Глоссарий

В скобках — источник: SA-2378.
Если источник не указан, определение сформулировано по контексту продукта, а спорные
детали вынесены в [[03-assumptions]].

## Роли

| Термин | Определение |
|---|---|
| Компания-заказчик | Юрлицо, которое платит исполнителям; её бухгалтер работает в сервисе. SA-2378 |
| Бухгалтер | Пользователь сервиса со стороны компании: загружает реестры, разбирает ошибки, контролирует выплаты. SA-2378 |
| Исполнитель-самозанятый | Физлицо, применяющее налог на профессиональный доход (НПД), получатель выплаты. SA-2378 |

## Документы и данные

| Термин | Определение |
|---|---|
| Реестр выплат | Пакет строк, загруженный бухгалтером за один раз: кому, сколько и за что платить. SA-2378 |
| Строка реестра | Одна запись реестра: один исполнитель, сумма, назначение платежа. |
| Обязательные поля строки | ФИО, ИНН, телефон для СБП, сумма, назначение платежа (`AS-01`). |
| Валидация реестра | Проверка файла и строк на формат, полноту и корректность до выплаты. |
| Отчёт об ошибках | Список строк, отклонённых валидацией, с причиной по каждой. |
| Маска ПДн | Скрытие части персональных данных в интерфейсе и отчётах (`AS-15`). |

## Деньги и выплаты

| Термин | Определение |
|---|---|
| Выплата | Перевод денег исполнителю; в MVP — только по СБП. SA-2378 |
| СБП | Система быстрых платежей: перевод по номеру телефона получателя. SA-2378 |
| Чек ФНС | Документ, подтверждающий доход самозанятого; сервис получает его по каждой выплате. SA-2378, `AS-07` |
| Аннулирование чека | Отмена чека при возврате выплаты; третья фича продукта, в работу не входит (`AS-08`). |
| Возврат | Возврат средств от исполнителя или банка; вне выбранных фич (`AS-08`). |
| Достаточность средств | Проверка баланса компании на весь пакет перед отправкой выплат (`CHK-10`). |
| Лимит одной выплаты | Максимальная сумма одной строки реестра (`AS-02`). |
| Лимит реестра | Максимальное количество строк и общая сумма одного реестра (`AS-02`). |

## Статусы и проверки

| Термин | Определение |
|---|---|
| Статус самозанятого | Признак того, что исполнитель зарегистрирован как плательщик НПД и не утратил статус. SA-2378 |
| Проверка статуса | Запрос в ФНС («Мой налог») перед каждой выплатой; обязательная процедура (`CHK-08`). |
| Утрата статуса | Исполнитель снят с учёта как самозанятый; выплата такому лицу запрещена (`O-02`). |
| Идемпотентность выплаты | Повторная отправка той же строки не создаёт второй перевод (`AS-13`). |
| Частичное исполнение | Ситуация, когда часть строк реестра выплачена, часть — нет (`AS-06`). |

## Интеграции и техника

| Термин | Определение |
|---|---|
| ФНС | Федеральная налоговая служба; источник статуса самозанятого и чеков. SA-2378 |
| «Мой налог» | Сервис ФНС для партнёров: проверка статуса и получение чеков. SA-2378 |
| Банк компании | Счёт, с которого списываются средства на выплаты. SA-2378 |
| API | Программный интерфейс интеграции; конкретные методы в описании не заданы (`AS-16`). |
| Ретрай | Повторная попытка операции после технической ошибки (`AS-05`). |
| DLQ | Очередь недоставленных сообщений после исчерпания ретраев (`AS-05`). |
