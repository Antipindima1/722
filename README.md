# ВыплатыПро — база знаний и артефакты

Учебный проект системного аналитика по продукту **ВыплатыПро** — сервис массовых выплат
самозанятым исполнителям. Здесь живут база знаний, правила работы ИИ-агента и навыки, по
которым агент готовит артефакты. Проектные факты берутся только из Jira и `knowledge/`.

## Структура

| Путь | Что внутри |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Правила поведения ИИ-агента: источники, формат ответов, маршрутизация по навыкам |
| [`knowledge/`](knowledge/) | Vault Obsidian: глоссарий, бизнес-правила, допущения, сущности |
| [`knowledge/00-index.md`](knowledge/00-index.md) | Карта знаний — точка входа |
| [`knowledge/01-glossary.md`](knowledge/01-glossary.md) | Глоссарий |
| [`knowledge/02-business-rules.md`](knowledge/02-business-rules.md) | Ограничения, обязательные проверки, статусы и переходы |
| [`knowledge/03-assumptions.md`](knowledge/03-assumptions.md) | Допущения `AS-xx` и открытые вопросы |
| [`skills/`](skills/) | Навыки агента: C4 L2, OpenAPI + Sequence, AsyncAPI, ER + DDL и «Смотрящий» |
| [`skills/README.md`](skills/README.md) | Каталог навыков и правила выбора |

Появятся при работе над артефактами: `artifacts/` (артефакты и отчёты `<артефакт>-check.md`,
`<артефакт>-review.md`) и `ai-log.md` (журнал ошибок агента).

## Продукт и фичи

**ВыплатыПро** — компания разом платит сотням самозанятых исполнителей и получает по каждой
выплате чек. Пользователи: бухгалтер компании и исполнитель-самозанятый.

| Фича | Что делает |
|---|---|
| Ф1. Загрузка и проверка реестра выплат | формат, обязательные поля, ИНН, дубли, суммы, телефоны |
| Ф2. Выплата по СБП | проверка статуса самозанятого, средства, лимиты, ретраи, чек ФНС |

## Навыки

| Навык | Артефакт | Проверка |
|---|---|---|
| `c4-container-diagram` | C4, уровень 2 | PlantUML C4 / Structurizr |
| `openapi-design` + `sequence-diagram` | OpenAPI + Sequence | Spectral |
| `asyncapi-design` | AsyncAPI | AsyncAPI CLI validate |
| `erd-data-model` | ER + DDL PostgreSQL | DDL в DBeaver |
| `smotryashchiy` | Проверка результата | Отчёт с обоснованными замечаниями |

## Как открыть

1. Склонировать репозиторий.
2. В Obsidian: `Open folder as vault` → папка `knowledge`.
3. Настройки Obsidian (`.obsidian/`) уже в репозитории: включены граф, backlinks, теги,
   поиск, шаблоны.

## Правила ведения

- **Факт** — утверждение из описания продукта или Jira со ссылкой на источник
  (`Описание продукта`) либо на правило в `knowledge/`.
- **Допущение** — всё, чего в описании продукта нет; нумеруется `AS-xx` и живёт в
  `knowledge/03-assumptions.md` с причиной и областью применения.
- Секретов, персональных данных (реальных ИНН, телефонов) и материалов с текущей работы
  в репозитории нет.
