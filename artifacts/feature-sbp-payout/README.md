# Ф2. Выплата по СБП — артефакты

- **Фича:** `SCRUM-2188` «Выплата самозанятым через СБП»
- **Истории:** `SCRUM-2191` (запуск выплаты), `SCRUM-2203` (ошибки и повторный запуск)
- **Источник требований:** `knowledge/features/feature-sbp-payout.md`,
  `knowledge/02-business-rules.md` §2.2, §4.3

## Состав

| Артефакт | Файл | Проверка |
|---|---|---|
| OpenAPI: запуск выплаты, статус, результат | `openapi-payouts.yaml` | Spectral |
| Sequence: проверки → выплата → результат → разбор ошибок | `sequence-payout.md`, `.puml`, `.svg` | рендер Kroki |
| AsyncAPI: события выплаты (ретраи, DLQ) | `asyncapi-payouts.yaml` | AsyncAPI CLI |
| Отчёты | `*-check.md`, `*-review.md` | — |

## Что должно быть отражено

- запуск только для реестра в статусе «Проверен» (`CHK-09`);
- подтверждение статуса самозанятого перед каждой выплатой (`CHK-08`, `AS-05`);
- достаточность средств и суточный лимит (`CHK-10`, `CHK-12`);
- идемпотентность по ключу `registry_id + row_id` (`CHK-07`, `CHK-11`, `AS-13`);
- ретраи 3 попытки 1/5/15 минут, затем DLQ (`AS-17`);
- частичный успех реестра (`AS-06`);
- отчёт: выплачено, ошибки с причиной, что ушло в DLQ (`SCRUM-2192`).
