## Что проверка НЕ подтверждает

- **Не проверена читаемость раскладки.** Рендер подтверждает синтаксис и наличие
  элементов, но не то, что диаграмма не перегружена и связи не пересекаются. Это смотрит
  человек.
- **Локального PlantUML нет.** На машине не установлены Java и plantuml.jar, поэтому
  рендер выполнялся через публичный сервис Kroki. Для повторной проверки без сети нужен
  локальный рендерер.
- **Смысловая верность диаграммы** проверке инструментом не поддаётся — это делает
  Смотрящий и человек (см. `artifacts/c4-container-review.md`).

## Как воспроизвести

```bash
# из корня репозитория
sed -n '/```plantuml/,/```/p' artifacts/c4-container.md | sed '1d;$d' > /tmp/c4.puml
curl -s -X POST https://kroki.io/plantuml/svg -H "Content-Type: text/plain" \
     --data-binary @/tmp/c4.puml -o artifacts/c4-container.svg
```

Проверка подписей:

```bash
grep -o '<text[^>]*>[^<]*</text>' artifacts/c4-container.svg | sed 's/<[^>]*>//g' | tr '\n' ' ' > /tmp/c4.txt
for l in "Сервис реестров" "Сервис выплат" "Очередь событий"; do grep -q "$l" /tmp/c4.txt && echo "OK $l"; done
```
