# Прогон правила E-08/E-09 по всем артефактам

- **Дата:** 2026-11-22
- **Правило E-08:** каждый лимит и каждая проверка из критериев приёмки отражены в артефакте
  либо явно вынесены в допущения.
- **Правило E-09:** у каждой проверки указан источник данных и владелец.
- **Проверено:** C4, OpenAPI + описание, Sequence, AsyncAPI + описание, ERD + DDL.

## Покрытие проверок CHK-01…CHK-12

| Артефакт | Отражённые проверки | Комментарий |
|---|---|---|
| `c4-container.md` | `CHK-01`, `CHK-07`, `CHK-08`, `CHK-10`, `CHK-12` | проверки в таблице трассировки; сама диаграмма проверки не описывает |
| `openapi-registry.yaml` | `CHK-01`, `CHK-05`, `CHK-07` (описания и коды) | контракты, а не номера правил: проверки отражены полями и кодами ответов |
| `openapi-registry.md` | `CHK-01`, `CHK-03`, `CHK-07` | трассировка к критериям приёмки |
| `sequence-registry.md` | `CHK-01`, `CHK-02`, `CHK-03…CHK-07` | шаги валидации и запрос в сервис выплат |
| `asyncapi-registry.yaml` | `CHK-09` (через статусы), `AS-20` | события не содержат проверок данных |
| `asyncapi-registry.md` | `CHK-01`, `CHK-09` | трассировка |
| `erd-registry.md` | `CHK-03`, `CHK-07`, `CHK-08` | ограничения схемы и связи |
| `schema-registry.sql` | `CHK-03`, `CHK-07` | CHECK-ограничения и уникальные индексы |

`CHK-08…CHK-12` относятся к выплатам (Ф2). В артефактах Ф1 они не обязаны присутствовать:
источники данных для них описаны в `knowledge/features/feature-sbp-payout.md`
(ФНС, реестр, счёт компании, таблица выплат, лимит СБП).
